# 写作指南

## 个人信息与学校结构

只在 `thesis-info.tex` 中替换题目、姓名、导师和日期，避免在类文件中直接写个人信息。`specialprogram` 固定为“网络赋能弹药技术博士人才培养项目”。指导教师预留两人，职称分别为教授与研究员；评阅人预留三人。将占位姓名替换为实际姓名，并同步填写两位英文导师信息。`studentnumber` 是预留数据项，当前确认版中文扉页没有学号行。

学校名称、独创性声明、版权使用授权书与页眉由类文件生成。不要把这些内容当作普通占位段落删除。声明签名位置保持空白，按学校要求签署。

`twoside` 会在扉页、声明和前置部分之间插入必要的空白背页，并保留原工程的页码规则；这些空白不是编译故障。改为 `oneside` 可取消这类补白，但正式提交前应确认所需打印方式。

## 章节、附录与正文

每个正文文件以 `\chapter{章标题}` 开始，按需要使用 `\section`、`\subsection` 和 `\subsubsection`。在 `main.tex` 的 `\mainmatter` 后增加或删除 `\input` 即可调整章节数。

正文各章统一采用原确认版的排版参数，不再限制为七章。附录使用 `\appendix` 开始，编号自动变为字母；不需要时同时删除该命令和附录的载入行。参考文献、致谢和成果部分保留各自的标题形式。

## 图、表、公式与引用

示例源码集中在 `chapters/chapter2.tex`。公式的 `\label` 放在公式环境中；图表可使用以下双语题注命令：

```latex
\sylufigcaption[fig:unique-key]{中文图题}{English caption}
\sylutabcaption[tab:unique-key]{中文表题}{English caption}
```

表题放在表格上方，图题放在图片下方。用 `\figrefcn{fig:unique-key}`、`\tabrefcn{tab:unique-key}` 和 `\eqrefcn{eq:unique-key}` 引用，避免手写编号。标签必须全篇唯一。

外部图片可存入 `figures/` 并用 `\includegraphics[width=0.8\linewidth]{figures/your-figure.pdf}` 插入。这个路径只是写法示例，需换成实际文件。优先使用清晰的矢量图，避免路径中的空格和不必要的特殊字符。

## 参考文献

替换 `reference/references.bib` 中所有虚构条目，再用 `\cite{文献键}` 在正文引用。当前模板沿用 GB/T 7714-2005 数字顺序样式和 BibTeX；不是 biblatex/biber 工程。不要混用两套文献工具。若学校另有版本要求，应单独核对后统一调整。

## 常见问题

- 提示只能使用 XeLaTeX：检查编译器，不能使用 pdfLaTeX。
- 引用显示问号：先查文献键和标签，再执行完整 latexmk 编译。
- 字体缺失：默认便携模式无需自备字体；确认版模式请查 `fonts/README.md`，同时注意 Overleaf 文件名大小写。
- 中文少见字缺失：查看日志中的 `Missing character`，选择覆盖该字符且允许使用的字体；不要把“成功生成 PDF”当成没有缺字。
- 题目或导师过长：检查扉页固定字段宽度，不能依靠正文自动换行规则修复。
- 新章节行距不一致：确认它位于 `\mainmatter` 与参考文献/附录之间，不要手动改变字号、行距或正文模式。
- 清理后需要重新编译：正常。`.aux`、`.bbl`、目录和日志都是可重新生成的文件，无需上传至 Overleaf。

## 提交前检查

替换全部占位信息与虚构条目，核实中英文一致性，检查引用、目录、字体、页面边界和图表清晰度。模板说明文字仅供学习，正式稿中应全部替换。排版要求以学校和学院当年的正式要求为准。

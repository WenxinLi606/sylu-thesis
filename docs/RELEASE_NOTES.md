# v1.0.0 · 首个公开版本

这是我面向沈阳理工大学学弟学妹整理的第一份公开版 LaTeX 学位论文模板。目前以博士学位论文为基础，希望帮助大家减少格式调整的反复，把更多时间留给研究与写作。

## 本版内容

- 沈阳理工大学中文及英文扉页、声明、学校页眉与页码。
- 两位指导教师（教授、研究员）与三位评阅人的占位信息。
- 固定特需项目名称：网络赋能弹药技术博士人才培养项目。
- 中英文摘要、正文、公式、居中三线表、双语题注、算法、参考文献、附录和致谢示例。
- 默认便携字体模式，以及可选的自备字体模式。
- 本地与 Overleaf 编译说明、编译脚本和纯源码包。

已在本地 TeX Live 2023 环境验证两种字体模式，并从干净源码包完整编译；尚未在 Overleaf 或 Windows/Linux 真机上实测。项目为个人整理的非官方模板，具体提交要求请以学校及学院当年的规定为准。

欢迎通过 Issues 或 Pull Requests 一起完善，让这份经验惠及更多学弟学妹。
